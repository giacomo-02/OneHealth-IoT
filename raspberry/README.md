
######################DESCRIZIONE DEL COMPONENTE#############################

Questo componente rappresenta il dispositivo Raspberry Pi utilizzato per la raccolta locale dei dati ambientali.

Il Raspberry Pi integra sensori fisici per il monitoraggio della temperatura dell'acqua e dell'ambiente, oltre ad attuatori per fornire feedback locali sullo stato della qualità dell'acqua.

Funzionalità principali:
- lettura del sensore di temperatura acqua DS18B20;
- lettura di temperatura e umidità ambientale tramite DHT11;
- gestione LED RGB KY-016 per indicare lo stato della qualità dell'acqua;
- gestione buzzer per segnalazioni di allarme;
- valutazione locale dello stato tramite soglie simulate.

########################TECNOLOGIE UTILIZZATE#################################

- Raspberry Pi
- Python
- DS18B20
- DHT11
- KY-016 RGB LED
- Buzzer
- GPIO Zero
- Adafruit CircuitPython
